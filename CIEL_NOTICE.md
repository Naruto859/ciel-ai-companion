# Ciel personal companion

This is a modified personal build of Andee, originally developed by KUAFUAI.
Copyright 2026 KUAFUAI. The upstream license and third-party notices are included
beside this notice and remain applicable.

Upstream source: https://github.com/kuafuai/andee
Ciel source: https://github.com/Naruto859/ciel-ai-companion

The November 2026 Ciel changes add a native mobile home and setup flow, direct
Gemini Live conversation, two procedural companion designs, and fixes for
device-command authorization, cancellation, permission handling and disclosure
of credentials in logs. The original default companion is retained.

This build does not represent an official KUAFUAI or Google release. No provider
API key is supplied; the owner configures their own key on their own device.
